- `CLAUDE.md`: agent rules and commands; keep it short
- `docs/tools.md`: MCP tool and event schemas
- `docs/GUIDE.md`, `docs/INSTALL.md`, `docs/SETUP.md`, `docs/PRIVACY.md`: the user guide, install, setup details and privacy

- `.github/workflows/ci.yml`: on every push to main and every pull request, `ruff check` and the quick tests (`-m "not slow"`) on GitHub's Windows, Ubuntu and macOS runners; the full suite stays a local step before a commit
